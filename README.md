# 📈 Market Balance : Valuation & Balance Dashboard

> **한국 증시 Now : Valuation & Balance**  
> 코스피 (KOSPI)와 코스닥(KOSDAQ)의 주가지수와 PER, PBR, RSI, ADR 및 고객예탁금/신용잔고, VKOSPI, 외인/기관 수급, 200일선 상회 비율 등 핵심 8대 보조지표를 단일 프레임 비교 차트로 구현하여 시장의 밸류에이션과 과열/침체 균형(Balance)을 다각도로 추적하는 종합 마켓 대시보드입니다.

---

## 🏛️ 1. 주요 기능 및 특징

### (1) 직관적인 사이드바 조회 설정
- **시장 선택**: `코스피 (KOSPI)` 및 `코스닥 (KOSDAQ)` 원클릭 전환 (`st.radio(horizontal=True)`)
- **지표 선택 (총 8대 핵심 시장 지표)**: 
  - **PER**: 시장 전체의 이익 대비 밸류에이션 수준 (배) 및 기간 평균선
  - **PBR**: 청산가치 대비 자산평가 수준 (1.0배 청산 기준선 및 역사적 안전마진)
  - **RSI**: 20거래일 모멘텀 상대강도 (`RSI(20)`, 과매수 70 / 과매도 30 밴드)
  - **ADR**: 시장 실제 체감온도 3중 합성 차트 (`ADR(14)` 핵심 추세선 + `당일 ADR(1)` + 주가지수, 120% 과열 / 75% 바닥권)
  - **예탁금&신용**: 금융투자협회(KOFIA FreeSIS) 공식 결제 공시(T+1 집계) 기반 고객예탁금(황금색 `#F59E0B`)과 신용융자 잔고(장미색 `#F43F5E`) 및 지수(하늘색 `#38BDF8`) 3중 고대비 비교 차트 (100% 실데이터 검증 완료)
  - **VKOSPI**: KOSPI 200 내재변동성 지수 (한국형 공포지수, 오렌지색 `#FB923C`, 30pt 패닉 매수 / 15pt 안도 상투 경계)
  - **외인&기관수급**: 시장 방향성을 결정짓는 외국인(적색 `#EF4444`) 및 기관(녹색 `#10B981`)의 기간 누적 순매수 (조 원) 및 다이버전스 분석
  - **200일선상회**: 시장 전체 종목 중 200일 이동평균선 상회 비율 (% > 200-MA, 네온 마젠타 `#E879F9`로 지수 하늘색과 뚜렷이 대비, 시장 건전성 Breadth 진단)
- **조회 기간 컨트롤**:
  - **조회 기간 (캘린더 직접 입력)**: 1990-01-01부터 최신 거래일까지 날짜 선택 (`st.date_input`, 라벨 숨김으로 깔끔한 입력창 유지)
  - **빠른 선택 (Quick Presets)**: `1W`, `2W`, `1M`, `3M` / `6M`, `1Y`, `YTD`, `MAX` 총 8개 옵션 가로 2행 4열 정렬 버튼 (기본값: `1Y`)
- **차트 표시 옵션**:
  - **일봉 캔들차트 기본 탑재**: 한국 거래소 표준 빨강(양봉)/파랑(음봉) 고대비 캔들스틱 적용
  - **이동평균선 (5, 20, 60, 120일선)**: 단기 수급부터 중장기 추세선까지 4개 핵심 이평선 동시 오버레이 및 토글 지원
  - **지수 로그 스케일 (Log Scale)**: 체크박스 토글 지원 (장기 시계열 복리 수익률 왜곡 방지 및 추세선 분석 지원)
- **하단 액션 버튼 (Type A 표준)**:
  - `[🔄 Update]`: 캐시를 초기화하고 최신 데이터를 동기화
  - `[🔍 조회]`: 선택 조건으로 화면 즉각 갱신

### (2) 고대비 액자형 카드 비교 차트 (Plotly Dual-Axis)
- **가이드 03 준수**: Tailwind Slate 다크 액자형 카드 테마 (`paper_bgcolor: #1E293B`, `plot_bgcolor: #0F172A`)
- **이중 Y축(Secondary Y)**: 주가지수 일봉 및 이동평균선(좌측 Y축)과 보조지표(우측 Y축)를 동일한 x축 시계열 위에서 통합 비교
- **단일 날짜 통합 호버 툴팁 (`hovermode='x unified'`)**: 중복 없는 날짜 헤더와 일봉 시고저종(OHLC), 이평선, 보조지표 수치를 단일 팝업으로 정밀 확인

### (3) 실시간 스마트 진단 KPI 카드 (4열 그리드)
- **KPI 1**: 최신 지수 및 전일대비 등락폭/등락률
- **KPI 2**: 선택 보조지표 현재 수치 및 전일대비 변동
- **KPI 3**: 시장 밸런스 상태 자동 진단 (예: `역사적 저평가 안전마진`, `과매수 경계`, `레버리지 과열`, `공포 매수 기회` 등)
- **KPI 4**: 조회 기간 내 최저 / 평균 / 최고 통계 요약 (지표 맞춤형)

### (4) 전략적 지표 해설 가이드 (Expander)
- 8대 지표 각각에 대한 상세 산출 배경과 실전 투자 전략(매수/매도/리스크 관리 관점) 해설 제공

### (5) 데이터 테이블 및 통일 규격 다운로드
- 최근 거래일 순 정렬 데이터 그리드 (선택 지표 관련 컬럼 우선 정렬)
- 통일 규격 CSV 다운로드 (`📥 CSV 파일 다운로드`) 및 엑셀 다운로드 (`📥 엑셀 파일 다운로드`) 지원

## 🛡️ 2. "00 App_AI_Template" 공통 표준 규칙 준수

1. **[가이드 01] 다크 테마 단일 모드 & 레이아웃 표준**:
   - `.streamlit/config.toml` 다크 테마 단일 모드 구성 (`headless = true`, `address` 미지정)
   - 메인 타이틀 (`2.0rem`, `#8AB4F8`, 가운데 정렬), 서브타이틀, 구분선, 섹터 소제목 (`1.20rem`) 규격 100% 준수
   - 하단 표준 법적 고지 푸터 삽입
2. **[가이드 02] 사이드바 UI/UX 단일 표준**:
   - 단일 `with st.sidebar:` 블록 및 사이드바 전용 CSS 주입
   - 가로 라디오 위젯, 5열 가로 프리셋 버튼, Type A 2열 가로 액션 버튼 배치
3. **[가이드 03] 차트 Plotly 디자인 표준**:
   - `STANDARD_CHART_THEME` 딕셔너리 기반 액자형 테마
   - `tickformat="%Y-%m-%d"`, `hoverformat="%Y-%m-%d"` 날짜 왜곡 원천 차단
4. **[가이드 04] 타임존 및 거래일 데이터 안전 규칙**:
   - KST (UTC+9) 명시적 변환
   - 15:45 이전, 새벽(00:00~08:59), 주말, 공휴일 안전 역추적
   - `@st.cache_data` 캐시 키 바인딩 (`target_date_key`)
5. **[가이드 05] 클라우드 무한로딩 방어 & 모듈 캐싱 방어**:
   - `socket.setdefaulttimeout` 절대 금지, 개별 요청 단위 명시적 타임아웃
   - 로컬 번들 캐시 최우선 로드 (Zero Network Startup: 첫 화면 0초대 로딩 보장)
   - 보조 모듈 `importlib.reload()` 강제 적용
   - 방어적 `**kwargs` 수용 API
6. **[가이드 06] 주가 데이터 수집 파이프라인 및 무결성 보장**:
   - 한국 대표 지수(KOSPI, KOSDAQ) 공식 네이버 fchart API 1순위 채택
   - yfinance / FinanceDataReader 폴백 3계층 방어선 구축
